# Documentation

`architecture.html` is a diagram written for the original project (Mos) and describes its
state at the time: paths, commands, the website, the release process and the minimum
system version in it may no longer exist. Treat it as history. The current rules are in
`AGENTS.md`, the module map in `.agents/docs/code-map.md`.

The plan and spec files the original project kept here (`plans/`, `superpowers/`) were
removed on 2026-11-11: they were working notes addressed to AI coding agents, with
commands of that project (among them running an agent without its sandbox and pushing to
`master`) that must not be followed in this one. They are still in the git history.
